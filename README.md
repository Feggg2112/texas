# 德州扑克多Agent游戏

基于 LangGraph State 的多 Agent 德州扑克游戏，三个性格各异的 AI Agent 一起打牌。

## 项目结构

```
texas/
├── .env                      # API Key 配置
├── requirements.txt          # 依赖包
├── texas_poker_agents.py     # 原始对话教学 Demo
├── texas_poker_game.py       # 游戏主程序（新）
├── poker_core.py             # 扑克牌核心逻辑
├── agent_config.py           # Agent 配置和 LLM 调用
├── game_nodes.py             # LangGraph 节点定义
└── game_display.py           # 游戏显示函数
```

## 当前实现（手牌阶段）

### 已完成功能

1. **发牌节点**：随机发两张手牌给三个玩家
2. **下注轮**：三个 Agent 依次行动（老鹰 → 小辣椒 → 老钱）
3. **行动决策**：每个 Agent 根据手牌和对手行动，通过 LLM 决定 fold/check/call/raise
4. **对话互动**：Agent 在行动时会说话，对话会影响其他 Agent 的判断
5. **判断赢家**：简化版手牌评估（高牌、对子、两对、三条、四条）
6. **筹码结算**：从各自筹码中扣除下注，赢家获得底池

### 三个 Agent 性格

- **老鹰**：冷静理性，数学派，注重 EV 和概率
- **小辣椒**：激进凶猛，频繁 bluff，制造压力
- **老钱**：稳健老练，注重读人和心理战

### 运行方式

```bash
python texas_poker_game.py
```

## 技术架构说明

### LangGraph State 流转

```
[Dealer 发牌] 
    ↓
[老鹰行动] → [小辣椒行动] → [老钱行动]
                                  ↓
                        ┌─────────┴─────────┐
                        ↓ continue          ↓ end
                    [老鹰]（下一轮）      [Judge 判断赢家]
                                              ↓
                                            [END]
```

### State 字段说明

- `hand_number`：当前第几手牌
- `chips`：三个玩家的筹码
- `pot`：当前底池
- `community_cards`：公共牌（Flop/Turn/River）
- `players_info`：玩家信息（手牌、下注、是否弃牌）
- `messages`：对话历史
- `stage`：游戏阶段（preflop/flop/turn/river）
- `hand_ended`：是否结束本手牌
